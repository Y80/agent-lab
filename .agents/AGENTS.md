# 用户级 Codex 指南

## 偏好

- 使用中文回应和维护说明文档。
- Python 相关任务优先使用 `uv`；跨目录一次性脚本依赖优先用 `uv run --with <package> python <script>`。
- npm 依赖管理工具优先使用 `pnpm`。
- 用户目录路径使用 `~`，不要写成 `/Users/<name>`。
- 把偏好和流程分开：短偏好放在 `AGENTS.md`，详细流程放到独立文档并按需引用。
- 当需要让大模型读取本地图片时，必须先使用 `$upload-public-images` 上传为公共图片 URL；不要直接发送本地路径、附件、`file://`、base64 或 data URI。
- 当用户发出的指令任务存在更合适、更符合最佳实践的方案时，应及时提出来；当智能体对任务有疑问时，也务必先提问。
