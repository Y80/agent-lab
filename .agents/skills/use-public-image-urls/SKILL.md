# 使用公共图片 URL

## 核心规则

当任务涉及“让大模型读取本地图片”时，先把本地图片变成公共可访问的图片 URL，再把 URL 传给模型。不要在模型对话中直接传本地图片文件、本地路径、`file://`、base64、data URI、内联二进制或其它本地图片格式。

## 工作流程

1. 判断目标是否需要模型看到图片内容。只要图片来自本地文件系统，并且会被放进模型对话、API 请求、工具调用参数或提示词中，就必须执行本流程。
2. 使用 `$upload-public-images` 上传图片到公共图床，并遵循它的安全规则：先确认图片适合公开，不上传密钥、隐私、公司敏感资料、未公开工作材料或用户未明确允许公开的文件。
3. 上传后验证 URL 可公开访问，且返回的是可被模型或浏览器读取的图片内容。
4. 在后续模型对话中只使用验证后的图片 URL，例如 Markdown 图片链接、`image_url` 字段或提示词里的 HTTPS URL。
5. 如果图片不能公开上传，或用户没有批准公开敏感图片，不要把图片发送给模型；说明原因并请用户提供可公开的图片 URL 或明确授权其它处理方式。

## 禁止事项

- 不要把本地绝对路径或相对路径发给模型作为图片输入。
- 不要把本地图片转成 base64、data URI、JSON 内联字节、HTML 内联资源或其它编码后内容发给模型。
- 不要把本地图片作为聊天附件、文件上传参数或非 URL 形式绕过本规则。
- 不要为了测试上传用户本地图片；需要测试时生成无敏感内容的临时测试图。

## 可接受输入

如果用户已经提供公共 HTTPS 图片 URL，可以先验证该 URL 是否可访问并直接使用；只有本地图片文件需要上传。
